# Site

The preview site: pages about Justin's construction AI work, three case studies,
a writing library, and the build he opens beside v2. Today it is the whole
product.

Product-level docs are one folder up, in [../](../).

## Where things stand

Designed, as a draft. Not built. The first milestone is a preview on a new
branch, and that branch does not exist yet. `main` and `v2` of
`justinyurasits.github.io` stay as they are.

**Code:** [`justinyurasits.github.io`](https://github.com/justinyurasits/justinyurasits.github.io),
branch `personal`, once Justin has merged this design and asked for the work.
Its CLAUDE.md will point back to this folder. Nothing in that repository
changes with this pull request.
