# JustinYurasits.com — Site Design

**Draft.** Only the decision log has entries, and every one is decided. The build decisions
come from the roll-up of `justinyurasits.github.io` #35–#50. Before them, the log holds:
- the stack: Astro, Markdown/MDX, GitHub Pages and GitHub Actions
- redirect pages for old addresses
- no database or CMS, and minimal dependencies
- three overrides for the site repository's `CLAUDE.md`

## 1. Scope and boundaries

**Open.** What the first release builds and what it defers follows from the
[product spec](../product-spec.md#1-product-scope). Visual rules (type, color, spacing, components) come from
[`brand-system`](https://github.com/justinyurasits/brand-system), not from this doc.
