# JustinYurasits.com — Site Design

**Draft.** Only the decision log has entries. The newest adopt the approved visual
design (2026-11-23). The build decisions come from the roll-up of
`justinyurasits.github.io` #35–#50, and rows a later decision replaced are marked
superseded. Before them, the log holds:
- the stack: Astro, Markdown/MDX, GitHub Pages and GitHub Actions
- redirect pages for old addresses
- no database or CMS, and minimal dependencies
- three overrides for the site repository's `CLAUDE.md`

## 1. Scope and boundaries

**Open.** What the first release builds and what it defers follows from the
[product spec](../product-spec.md#1-product-scope). Visual rules (type, color, spacing, components) come from the personal sub-brand in
[`brand-system`](https://github.com/justinyurasits/brand-system), `brands/personal/`
(BRAND-004), not from this doc.
